The DATA fixture uses temporary SQLite files under `os.tmpdir()` and random
loopback ports. The new helper verifies those boundaries and rejects existing
service ports. The reused `DataStack` injects its existing permissive **test-only
rate limiter** to allow synthetic account setup; genuine session, CSRF, sender,
membership and crypto validation still run. These new tests do not assess rate
limits. No production limiter/configuration was changed.

All client stores are explicitly named `a1-fixture-<UUID>` in process-local
fake IndexedDB; no existing browser profile or default browser key database is
opened. Device signing/agreement keys are generated by the production client for
synthetic accounts. Tests check identity/non-extractability and continued crypto
use without private-key export. A three-device case obtains two genuine signed,
independently encrypted concurrent edits and verifies the losing branch before
testing rollback rejection.

Browser checks use a fresh nonpersistent Chrome context at intercepted
`https://a1-platform-fixture.invalid`, with outbound requests blocked. Databases
are named `a1-platform-only-<UUID>` and contain only a `sentinels` store. Their
generic schema-version changes are browser-platform fixtures, **not watermark
format 2**. No account/key store, new-format head, migration journal or quarantine
policy is created there. Closing the disposable context removes only its owned
test data. Real application cross-tab format-2 enforcement remains pending.

## Status meanings

- **Current:** executable assertions against production format-1 behavior. They
  protect useful existing guarantees but do not establish the proposed protocol.
- **Prerequisite/limitation:** real browser storage behavior needed for later
  implementation. A passing old-cache limitation check demonstrates that a
  database handle closing does *not* secure an old reader.
- **Known failing:** an actual protection assertion fails with a nonzero process
  exit. These failures are retained; no expected-failure wrapper swallows them.
- **Pending format 2:** `test.todo` has no callback and executes no assertion.
  Node may print a checkmark alongside `# TODO`; that is not passing protection
  coverage. All 37 complete format-2 acceptance contracts remain pending.

The original [five adversarial probes](../server/test/manual/revision-watermark-review.check.ts)
were not edited, replaced, skipped or weakened. Their two A2 passes and three
A1 failures must still be reported separately from the ordinary green suite.
